# تقرير تنفيذ DEELA Books

التاريخ: 27 نوفمبر 2026
المستودع والفرع: `mzo77/DEELA-V2` / `feature/deela-books-private-marketplace`

## حالة النشر والخصوصية

- نشر `deela-books` على Supabase بالإصدار 18، ونشر `deela-books-vault` بالإصدار 13.
- المتجر يبقى خاصًا (`site_public=false`) والمدفوعات الحية غير مفعلة (`payments_live=false`). الكتالوج والملفات المحمية يرفضان الطلب غير المصادق عليه.
- نُشر تحديث صفحة الدخول على GitHub Pages بعد نقل زر الخروج إلى شريط الحساب بدل وضعه العائم فوق الصفحة. نجح سير نشر الصفحة `45934690200` وسير تهيئة الصفحات `45934690450`؛ الصفحة تظل شاشة دخول فقط بلا كتب عامة.
- رابط لوحة المالك: https://mzo77.github.io/DEELA-V2/books-private/ . بوابة البائع الخاصة: https://mzo77.github.io/DEELA-V2/books-private/seller/ .
- تطبيق المالك مستقل بمعرّف `com.deela.books.admin` ولا يستبدل تطبيق DEELA الحالي `com.deela.apps`. يُفتح عبره مركز المالك الحالي ويتصل بخادم DEELA Books.

## الخصائص المنفذة

- رفع الشعار والخلفيات والبنرات من الجهاز مباشرة إلى التخزين الخاص، مع تحقق النوع والحجم وروابط قصيرة العمر.
- إدارة الأقسام والتصنيفات: إنشاء وتعديل وحذف وترتيب وإخفاء، وصف وخامة وصورة وزخرفة وألوان مستقلة. توسعت لوحة الألوان إلى 17 متغيرًا و8 لوحات، ومكتبة الخامات والزخارف إلى 22 نمطًا.
- التصنيفات الديناميكية للروايات تتجاوز القوائم الثابتة. يختار البائع قسم روايته، ويمكن للمالك نقل رواية إلى قسمها الصحيح مع إشعار البائع.
- إدارة عدة بنرات مع الحركة والجدولة، وقسم الروايات والكتب في واجهة المتجر.
- إشعارات بائع للإعجابات والمشاهدات الجديدة، مع سجل وإمكانية القراءة. الموجز داخل التطبيق يعاد تحديثه دوريًا؛ إشعارات الخلفية بعد إغلاق التطبيق تحتاج إعداد FCM/Web Push.
- إعلان إطلاق مدفوع اختياري: يحدد المالك السعر والتفعيل، ويطلب البائع إعلانًا لكتاب منشور ويقدم مرجع التحويل. لا ينشره النظام حتى يتحقق المالك يدويًا من الإيداع. الخدمة معطلة والسعر صفر، ويمنع الخادم الطلب والنشر ما دام المتجر خاصًا. الموجز داخل التطبيق يدعم الإعلان؛ إرسال إشعار الهاتف للجميع بالخلفية يحتاج FCM.
- قائمة المستخدمين تعرض بائعي DEELA Books فقط، ولا تخلطهم بمشتركي تطبيقات DEELA الأخرى. حساب المالك محمي من الحظر أو الإيقاف عبر واجهة الخادم.
- إعداد دخول البائعين واستعادة كلمة المرور متاح. نافذة الدخول محسنة للجوال، وزر الخروج لا يغطي المحتوى.
- صفحة إعداد المدفوعات تبقى للاختبار والإعداد فقط؛ لا تسجل دفعًا ناجحًا ولا تفعّل تحصيلًا حقيقيًا.
- APK رسمي مستقل وموقّع بالشهادة الدائمة بالإصدار 1.0.4، بمعرّف الحزمة `com.deela.books.admin` وأيقونة كحلية تحمل كتابًا مفتوحًا ذهبيًا وعبارة DEELA ADMIN البيضاء. مسار GitHub Actions يتحقق من شهادة APK ومعرّف الحزمة قبل رفع الناتج؛ رقم الإصدار يزيد لتثبيت التحديث فوق النسخ السابقة.

## التحقق المنفذ

- تأكدت من نشر Edge Functions: `deela-books` إصدار 18 و`deela-books-vault` إصدار 13.
- بقيت إعدادات الخصوصية والدفع كما هي: `site_public=false`, `payments_live=false`; لا يوجد تحصيل فعلي أو إعلان مدفوع يمكن أن يُنشر قبل ضبطه والتحقق اليدوي.
- نجح `node --check` لملفي JavaScript، وتطابق أصول الويب وأندرويد بعد مزامنتها، ونجح `git diff --check`.
- نجح سير النشر إلى GitHub Pages بعد تحديث صفحة المالك إلى شريط حساب متوافق مع الجوال.
- نجح سير APK الرسمي 1.0.4 (GitHub Actions run `45934233674`) في التحقق من التطبيق والأيقونة، وبناء APK، وتوقيعه، والتحقق من البصمة الرسمية ورفع الملف. نجح سير المتجر الخاص `45933035899` في فحوص التكامل والخصوصية وبناء تطبيق DEELA الأساسي 0.9.16.
- اجتاز سير السوق الخاص السابق فحوص الخصوصية والـ API وCORS وواجهة الدخول. يجب إعادة التحقق على الالتزام الجديد بعد اكتمال النشر.
- لا تتوفر جلسة مصادق بها للمالك/البائع ولا جهاز Android موصول؛ لذلك لا أدعي إجراء دخول فعلي أو رفع من هاتف أو تجربة end-to-end لكل زر.

## المتطلبات الخارجية المتبقية

- SMTP موثوق وقوالب البريد لإرسال OTP واستعادة كلمة المرور، ومزود SMS معتمد.
- OAuth Client ID/Secret لـGoogle وApple وتهيئة redirect URIs.
- FCM أو Web Push لإرسال التنبيهات عند إغلاق التطبيق، مع مفاتيح VAPID/FCM محفوظة كأسرار.
- اختيار سعر إعلان الإطلاق، وحساب التحويل أو حساب تاجر. الخدمة الآن متوقفة وسعرها صفر؛ لا تُرسل أموالًا لها قبل الإطلاق الرسمي.
- بيانات حسابات بوابات الدفع، إعداد الضرائب والفواتير والاسترداد، ثم موافقة منفصلة لتشغيل الدفع الحقيقي. لم تُفعّل أي بوابة.
- مراجعة سياسات الجلسات والأجهزة والتحقق الثنائي عند اختيار مزودها؛ إدارة الحظر الحالية لا تلغي جلسات Supabase تلقائيًا.
- جلسة مالك/بائع اختبارية وجهاز حقيقي للتحقق اليدوي من تدفقات تسجيل الدخول ورفع الصور والتنبيهات وAPK بعد التثبيت.
