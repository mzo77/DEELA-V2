# تقرير تطوير DEELA Books

التاريخ: 27 نوفمبر 2026
المستودع/الفرع: `mzo77/DEELA-V2` / `feature/deela-books-private-marketplace`

## الحالة الحالية

- الخادم `deela-books` يعمل بالإصدار 12، وخدمة الملفات الخاصة `deela-books-vault` بالإصدار 6.
- بقي `site_public=false` و`payments_live=false` كما كانا؛ عرض الكتب والملفات المحمية لغير المالك يرجع 403.
- أضيفت جداول الأقسام والبنرات المجدولة وضوابط حظر المستخدم، وإعدادات المدفوعات الاختبارية. RLS مفعّل على الجداول الجديدة ولا توجد سياسات تمنح الوصول المباشر؛ الوصول يمر عبر وظيفة الخادم التي تتحقق من دور المالك.

## الخصائص المنفذة

- رفع شعار وخلفية وبنر من الجهاز إلى تخزين خاص بصيغ PNG/JPG/WebP وبحد أقصى 3MB للصورة. روابط التخزين الموقعة قصيرة العمر.
- إنشاء/تعديل/حذف الأقسام وتصنيفاتها، وترتيبها وإخفاؤها، وإضافة الوصف والخامة والصورة.
- إنشاء/تعديل/حذف البنرات، مع الرابط الآمن والحركة وترتيب الظهور وجدول البداية والنهاية.
- إضافة صفحة مركز المدفوعات في وضع إعداد اختباري فقط: Tap وMyFatoorah وMoyasar وتمارا وتابي والتحويل البنكي، والضريبة ونافذة الاسترداد والخصومات. لا تحفظ الصفحة أسرار مزود الدفع ولا تنشئ مدفوعات ناجحة.
- قائمة حسابات المالك وإيقاف/إعادة تفعيل الحسابات العادية. حساب المالك محمي، وفحص الحظر يتم في كل طلب إلى خدمة الكتب.
- حزمة Android منفصلة بمعرّف `com.deela.books.admin`، تطبيقها لا يستبدل `com.deela.apps`، ويفتح بوابة المالك الحالية ويدعم اختيار الصور من الجهاز. سير العمل المضاف يبني APK الإصدار الرسمي ويوقّعه بالشهادة الرسمية المحفوظة كسر GitHub، من دون نشر إصدار عام.

## التحقق المنفذ

- قراءة إعدادات المشروع ومخطط DEELA Books وحالة الخادم قبل التعديل.
- تطبيق توسعة قاعدة البيانات والتحقق من أن إعداد المتجر ظل خاصًا والمدفوعات الحقيقية ظلت معطلة.
- فحص صحة API وخدمة الملفات الخاصة.
- طلب الكتالوج والأصول المحمية دون جلسة: كلتاهما أعادتا 403.
- `node --check` لواجهة الكتب؛ مقارنة ملفات الويب مع النسخة المضمّنة في تطبيق DEELA؛ `git diff --check`؛ وتحليل ملفات XML.
- لم يمكن بناء APK في بيئة العمل محليًا لأن تنزيل Gradle محجوب عنها. سير GitHub Actions الرسمي ينفذ بناء Android والتوقيع واختبار بصمة الشهادة قبل إتاحة ملف APK الخاص.
- لم تُنفذ عمليات مالك مصادق بها أو تجربة رفع على جهاز حقيقي لعدم توفر جلسة المالك أو جهاز اختبار في هذه البيئة.

## متطلبات خارجية متبقية

- **البريد OTP واستعادة كلمة المرور:** إعداد مزود البريد/SMTP وقوالب ورسائل التحقق في Supabase Auth.
- **SMS:** اعتماد مزود SMS وإضافة مفاتيحه واختبار وصول الرسائل.
- **Google وApple:** بيانات OAuth الخاصة بالتطبيقين، وتهيئة redirect URIs في Supabase ومزودي الهوية.
- **التحقق الثنائي وإدارة الجلسات والأجهزة:** سياسات AAL2، تسجيل الأجهزة، وإجراءات إبطال الجلسات. الحظر الحالي يمنع استدعاءات API للكتب بعد إعادة التحقق، لكنه لا يدير جلسات Supabase أو أجهزة المستخدم المسجلة.
- **المدفوعات الحقيقية والفواتير والاسترداد:** حساب تاجر معتمد وبيانات كل بوابة، قواعد ضريبة/فواتير معتمدة، ثم موافقة منفصلة على تفعيل الدفع الحي. لم تُفعّل أي بوابة.
- **APK الرسمي:** يتطلب نجاح أسرار توقيع DEELA الحالية في GitHub Actions؛ لن يُعرض ملف غير موقّع أو موقّع بشهادة مؤقتة على أنه رسمي.

لوحة المالك تبقى على بوابة DEELA Books الحالية: `https://mzo77.github.io/DEELA-V2/books-private/`.
