# ديلا — لوحة المالك الجديدة والقوة الغاشمة ⚡

## وضع التسليم

- الإصدار الرسمي للمشتركين هو 0.9.8. **لا تُنشئ Release/Tag عامًا لإصدار 0.9.9 إلا عندما يطلب المالك نشره.**
- نسخة المراجعة الموقّعة 0.9.9 تنشأ عبر مسار `.github/workflows/deela-owner-internal-review.yml` وتحفظ APK كـ Actions artifact فقط دون تحديث `/releases/latest`.
- تستخدم النسخة التجريبية الخاصة شهادة `deela_release` نفسها للإصدار الرسمي 0.9.8 (توقيع متطابق) لتثبيتها فوقه مع الاحتفاظ بالبيانات.
- واجهة لوحة المالك في `DeelaOwnerScreen.kt`: لوحة الإحصائيات، الطلبات، إدارة المشتركين، التحديثات، الرسائل، السجلات والقوة الغاشمة. تغيير الواجهة موجود في فرع المراجعة، لا في الإصدار الرسمي المنشور.
- مكتبة أدوات المشروع الأول الأصلية الإصدار 3.7 موجودة في `app/src/main/assets/deela_owner_toolkit.html`، وأعيد توظيفها في `DeelaOwnerToolkit.kt`. تشمل دليل 16 أمرًا، مختبر البرمجة، تحليل ملفات الألعاب/APK/ZIP، محرك البحث المحلي، GitHub Explorer، أدوات المطور ومركز الأمان.
- **الحدود:** تحليل الملفات يعمل فقط للملفات التي يختارها المالك ولا يفك التشفير أو يتجاوز حماية الجهاز. ولا تُنفّذ الأكواد التي يولدها الذكاء الاصطناعي تلقائيًا.

## الذكاء الاصطناعي — إعداد اختياري ضروري للتوليد الفعلي

الخادم على Supabase (Edge Function `deela-owner-ai`) منشور ومحصور على المستخدم الموثّق في `profiles.role='owner'`. اتصالاته بـ OpenAI من الخادم فقط. لا تُضمّن أي مفاتيح خاصة في Android، GitHub أو HTML.

فعّل التوليد بوضع متغير السر في Supabase Edge Function Secrets:

**الاسم:** `OPENAI_API_KEY`

**القيمة:** مفتاح OpenAI API خاص بالمالك. لا تشاركه في المحادثة أو مستودع GitHub. رصيد API وفواتيره منفصلة عن اشتراك ChatGPT.

**اختياري:** `DEELA_AI_MODEL`، والقيمة الافتراضية `gpt-5.4-mini`.

لا يتطلّب هذا الأمر تغيير APK لأن الوظيفة تقرأ الأسرار من خادم Supabase أثناء التشغيل.

**التشغيل:** افتح لوحة المالك ← القوة الغاشمة ⚡ ← مختبر البرمجة، اكتب الطلب، واضغط «تنفيذ بالذكاء الاصطناعي». يظهر النص ويمكن نسخه أو حفظه.

## الأمان

- لا يُقبل طلب AI بدون جلسة مستخدم موثّقة **وصلاحية owner** تُقرأ من الخادم.
- يحتفظ الخادم بسجل استخدام مقيّد (معرّف المالك، وقت الطلب، النموذج، عدد الأحرف) دون الاحتفاظ بنص الطلب.
- الحد 20 طلبًا متحركًا خلال 24 ساعة، وطول الطلب 5000 حرف، وحد أقصى 2400 رمز للناتج.
- قاعدة `deela_ai_usage` مُعدّة بـ RLS وممنوعة من أدوار `anon` و`authenticated` (متاحة فقط لـ service_role).
- مفتاح OpenAI لا ينتقل إلى WebView، والملفات المحلية التي يفحصها المتصفح لا تُرسل إلى OpenAI تلقائيًا.

## اختبارات النسخة

- تحقّق من نجاح `:app:assembleRelease` و`:app:testDebugUnitTest --tests 'dev.aurastore.store.data.AppReleasesTest'`.
- تحقّق أن `DEELA-0.9.9-owner-review-signed.apk` يحمل حزمة `com.deela.apps` وتوقيعًا مطابقًا لشهادة الإصدار الرسمي.
- اختبر فتح تبويب القوة الغاشمة ثم فحص ملف تجريبي وتصدير التقرير؛ افتح المختبر وراقب الحالة (إما جاهز أو يطلب `OPENAI_API_KEY`).
- تأكد أن المشتركون لا يرون 0.9.9 في `https://github.com/mzo77/DEELA-V2/releases/latest` قبل إذن النشر.
