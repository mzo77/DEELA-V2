# وكيل ديلا البرمجي العربي 🤖 — داخل القوة الغاشمة

## ما أُنجز

أضيف تبويب **وكيل البرمجة 🤖** إلى أدوات القوة الغاشمة في لوحة المالك (نسخة مراجعة أندرويد 0.9.10)، مع إملاء صوتي بالعربية السعودية وزر لإنشاء مهام OpenCode.

كل من الأدوات التالية يحتوي على زر **حوّل الطلب إلى وكيل البرمجة**:
- مختبر البرمجة
- دليل الأوامر
- فحص ملفات الألعاب محليًا (ترسل صيغة الطلب، **وليس الملفات نفسها**)
- GitHub Explorer
- أدوات المطور
- مركز الأمان

التعديلات لا تنفذ فوق المشتركين؛ GitHub Actions يشغّل OpenCode في فرع مستقل، ويرفع ملف مراجعة وإحصاءات التغييرات دون إنشاء GitHub Release رسمي.

## مجانية الخدمة

- OpenCode برنامج مفتوح المصدر.
- النموذج الحالي: `opencode/mimo-v2.6-flash-free`، وهو مجاني حاليًا ضمن حدود استخدام مزوده وقد ينتهي توفره.
- GitHub Actions تخضع لحدود خطة ومستودع GitHub. الاشتراك المدفوع في OpenAI **غير مطلوب** للوكيل.
- لا يُستخدم مفتاح `OPENAI_API_KEY` للوكيل؛ مختبر الذكاء الاصطناعي النصي القديم خدمة أخرى يمكن تركها غير مستخدمة.

## تشغيل المهمة الآن — الطريقة اليدوية بلا أسرار إضافية

1. سجّل الدخول بحساب المالك في تطبيق ديلا 0.9.10 (مراجعة خاصة).
2. افتح «القوة الغاشمة ⚡» ثم «وكيل البرمجة 🤖» أو زر التحويل من أي أداة.
3. اكتب طلبًا عربيًا أو اضغط «🎙️ إملاء صوتي بالعربي» وراجع النص.
4. وافق على أن وصف المهمة سيُرسل إلى GitHub (مستودع عام؛ لا تذكر أسرارًا أو بيانات مشتركيك).
5. اضغط زر الإرسال. إذا لم يكن GitHub مربوطًا بخادم ديلا، سيُنسخ طلبك تلقائيًا وتفتح GitHub Actions.
6. اختر **Run workflow** ثم الصق النص في **task** واضغط Run workflow للتأكيد.
7. راقب `DEELA Arabic Coding Agent (Free Preview)` في GitHub Actions. ستجد تغييراتك في ملف **DEELA-ARABIC-AGENT-REVIEW** بداخل Artifacts.
8. إذا كان إنشاء PR تلقائي غير مفعل في إعدادات GitHub، يُنشئ الوكيل فرع المراجعة ويعطيك رابط «Create pull request» في ملخص التشغيل. يمكن أيضًا للمساعد إنشاء PR عبر أداة GitHub المتصلة.

## تفعيل زر الإرسال المباشر من داخل التطبيق — إعداد مجاني مرة واحدة

يحتاج الخادم إلى مفتاح GitHub **مخصص فقط لتشغيل workflow**؛ لا يُحفظ المفتاح داخل APK أو المحادثات أو مستودع GitHub:

1. افتح `https://github.com/settings/personal-access-tokens/new`.
2. اختر **Fine-grained personal access token** باسم مثل `DEELA-AGENT-DISPATCH`.
3. Repository access: **Only select repositories** ثم اختر `mzo77/DEELA-V2`.
4. Repository permissions: **Actions: Read and write**. اترك أي صلاحيات إضافية في الحد الأدنى. (Metadata: Read تظهر تلقائيًا).
5. اختر انتهاء صلاحية مناسبًا (30 إلى 90 يومًا) واضغط **Generate token**. انسخ القيمة مرة واحدة، ولا ترسلها في المحادثة.
6. افتح `https://supabase.com/dashboard/project/rxlynynjetajtsqlhkrq/settings/functions` ثم **Edge Function Secrets**.
7. احفظه باسم `DEELA_GITHUB_TOKEN` وقيمة المفتاح المنسوخ.
8. بعدها يرسل زر الوكيل الأمر تلقائيًا من التطبيق إلى `deela-owner-agent` على Supabase، الذي يتحقق من حساب المالك وحد 5 مهام كل 24 ساعة، ويطلب تشغيل workflow على GitHub.

عند غياب المفتاح يبقى التشغيل اليدوي متاحًا مجانًا. لا تسلم مفتاح GitHub عامًا واسع الصلاحيات.

## الأمان

- وكيل OpenCode يعمل في GitHub Actions على فرع التطوير، **بدون مفاتيح Supabase أو توقيع APK أو GH_TOKEN** في خطوة تنفيذ النموذج.
- سياسة النظام تمنع التعامل مع ملفات الشهادات والأسرار وأوامر git push أو gh خلال تنفيذ النموذج.
- بعد عمل النموذج تحفظ التغييرات ضمن مسارات مصدر معتمدة فقط؛ تُراجع الشيفرة قبل الدمج.
- يمكن للنموذج اقتراح تعديل غير صحيح. اختبر كود Android قبل اعتماده. لا تدخل بيانات المستخدمين الحقيقية إلى النموذج المجاني.
- **الإصدار الرسمي للمشتركين ما زال 0.9.8**؛ حتى APK 0.9.10 للمراجعة فقط، ولا يُطرح رسميًا إلا بموافقة المالك.
