# DEELA Books — Private Multi-vendor Book Marketplace

**الحالة:** منصة حقيقية متصلة بقاعدة بيانات DEELA، لكن الويب خاص بالمالك فقط.

## رابط المعاينة

https://mzo77.github.io/DEELA-V2/books-private/

تظهر صفحة تسجيل دخول فقط عبر GitHub Pages. لا يتم وضع كود الموقع أو الكتب في هذا المسار العام. بعد مصادقة المالك، تُحمّل الملفات المحمية من Supabase Edge Function deela-books-vault.

## الملفات الأساسية

- site/index.html — صفحة المتجر بالعربية.
- site/style.css — تصميم أصلي للجوال والكمبيوتر بالكحلي والنعناعي والبنفسجي.
- site/app.js — البحث، التصفح، المنتجات، المفضلة، فتح المتاجر، رفع الكتب، الطلبات، الرسائل، البلاغات، التقييمات، إدارة المالك.
- site/icon.svg — أيقونة أصلية.
- server/deela-books.ts — خدمة السوق REST والتحقق من المستخدم.
- server/deela-books-vault.ts — إتاحة الواجهة للمالك فقط.
- app/src/main/assets/books — الموقع المضمّن في تطبيق DEELA الرسمي.
- app/src/main/java/dev/aurastore/store/auth/DeelaBooksOwnerActivity.kt — مركز كتب مدمج عبر WebViewAssetLoader مع منتقي الملفات.

## قاعدة البيانات

الجداول الموجودة فعليًا في Supabase، جميعها RLS مع منع القراءة المباشرة للزوار والمشتركين:

deela_books_sellers, deela_books_listings, deela_books_orders, deela_books_order_items,
deela_books_favorites, deela_books_reviews, deela_books_messages,
deela_books_reports, deela_books_settings.

الملفات مخزنة في bucket خاص: deela-books-covers و deela-books-private-files. رابط تنزيل الكتب الرقمية موقّت ويطلب صلاحية الشراء أو حساب المالك.

## طريقة التجربة

1. افتح رابط المعاينة وسجل دخول حساب المالك.
2. من انشر كتابك افتح متجرًا (حساب المالك معتمد تلقائيًا).
3. أضف كتابًا مع البيانات والسعر والغلاف، وأرفق PDF أو EPUB أو MP3 حسب نوعه.
4. راجع الكتاب واعتمده من مركز المالك.
5. أضفه للسلة وأرسل طلبًا للمراجعة.
6. راجع طلبات المشترين، وتأكد من استلام الدفع يدويًا قبل تأكيد حالة الدفع.
7. استخدم المفضلة والرسائل والبلاغات والإعدادات من نفس المنصة.

## حدود جاهزية الإطلاق

- بوابة الدفع الإلكتروني الحقيقية غير مرتبطة، ولا تُحصّل مبالغ آليًا.
- شركة التوصيل، أسعارها الفعلية، والتتبع التلقائي غير مرتبطة؛ يمكن إدخال رقم تتبع يدويًا.
- تسوية عمولة البائعين وإرسال الحوالات تحتاج موفر دفع وتحققًا قانونيًا.
- لا توجد مبيعات أو تقييمات مزيفة؛ النماذج الظاهرة عند خلو المتجر موصوفة بوضوح.
- التقييم متاح بعد اكتمال الطلب؛ بلاغات حقوق النشر تمر عبر مراجعة المالك.
- لا يمكن إعلان اكتمال اختبار جميع العمليات في حسابات حقيقية دون تجربة المستخدم على هاتفه.

## سياسة الخصوصية الحالية

- صفحة تسجيل الدخول فقط عامة. HTML/CSS/JavaScript الخاص بالمتجر محمي على الخادم.
- كل طلب سوق يتطلب مصادقة المالك ما دام site_public=false.
- لا تنشر ملفات site على مسار عام ولا تفتح الموقع للجميع بدون إذن المالك الصريح.
- لا يوجد إصدار APK منشور للمشتركين عبر هذا الفرع؛ اختبار 0.9.15 منفصل عن main.
